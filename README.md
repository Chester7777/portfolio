# Evgeny Chausov — portfolio

Live: **https://chester7777.github.io/portfolio/**

Personal portfolio of a front-end developer (React, TypeScript, Redux-Saga, AI agents).

## Stack

- React 18 + TypeScript, built with Vite
- Three.js via `@react-three/fiber` and `@react-three/drei` — 3D hero scene and interactive skills sphere
- Framer Motion — scroll reveals, tilt cards, page transitions
- Plain CSS, responsive down to 360 px, respects `prefers-reduced-motion`

## Scripts

```bash
npm install
npm run dev      # local dev server
npm run build    # type-check + production build into dist/
npm run deploy   # build and publish dist/ to the gh-pages branch
```

The 2021 version of this portfolio lives in the `legacy-2021` branch.
